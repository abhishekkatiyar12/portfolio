# 🚀 Personal Portfolio - Abhishek Katiyar

This is my personal **portfolio website** built with **React (Vite) +
Chakra UI + Framer Motion**.\
It highlights my **skills, experience, projects, and achievements** in a
clean and modern UI.

------------------------------------------------------------------------

## ✨ Features

-   ⚡ Built with **Vite** for fast performance
-   🎨 Styled using **Chakra UI** (responsive design)
-   🎭 Smooth animations with **Framer Motion**
-   📱 Fully responsive (mobile-first design)
-   🔗 Direct links to **GitHub, LinkedIn, and LeetCode**
-   🖼️ Dynamic sections: About, Skills, Experience, Projects, Education
-   🌌 Animated background elements (blobs & gradients)

------------------------------------------------------------------------

## 🛠️ Tech Stack

-   **Frontend:** React, Vite, Chakra UI, Framer Motion
-   **Icons:** React Icons
-   **Other Tools:** Axios, React Router, React Toastify, React Typing
    Effect
-   **Version Control:** Git & GitHub
